death rates across council areas

https://www.nrscotland.gov.uk/publications/deaths-time-series-data-2024/

  1. pick an age group.
  2. pick two LAAs
  3. how many deaths in that age group in that year for each LAA?
  4. how many people were in that age group that year for each LAA?
  5. what is the crude death rate for each LAA? (ndeaths/total pop)
  6. what would the death rate for each LAA be if you held the proportion of that age group at the average?
  7. how much of the difference in crude rates can be attributed to this compositional difference between LAAs?

EXAMPLE:

laa n_people n_over60 deaths_over60
Glasgow City 650300 128902 5287
Edinburgh 530680 113979 3877
... ... ... ...

decomp

scotlaa |>
  mutate(
    avgprop = mean(n_over60/n_people),
    avgover60deathrate = mean(deaths_over60 / n_over60),
    stdrate1 = avgprop* (deaths_over60 / n_over60) * 1e3,
    stdrate2 = (n_over60/n_people) * avgover60deathrate * 1e3,
    cr = deaths_over60/n_people*1e3
  ) |> select(stdrate1,stdrate2,cr) |>
  apply(2,diff)
  stdrate1   stdrate2         cr 
-1.4456220  0.6212492 -0.8243728

of the crude rate difference (Edinburgh is 0.82 deaths per 1000 lower than glasgow), 175% this difference would happen if they only differed in the ‘over60s death rate’.

-75% of the difference would happen if they only differed in the age demographic. i.e., Edinburgh would have a higher death rate than glasgow!

  • -1.4456220 / -0.8243728 * 100 = 175
  • 0.6212492 / -0.8243728 *100 = -75
